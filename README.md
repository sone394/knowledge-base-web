# knowledge-base-web

基于 Vite + React + TypeScript + Tailwind CSS 的知识库前端项目。

## 运行

```bash
cd knowledge-base-web
npm install
npm run dev
```

浏览器访问 http://localhost:5173

## 脚本

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发服务器 |
| `npm run build` | 生产构建 |
| `npm run preview` | 预览构建结果 |

## 路由

| 路径 | 页面 |
|------|------|
| `/` | 主页 Home |
| `/notes/edit` | 笔记编辑 NoteEditor |
